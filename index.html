AI Token Counter

A browser extension that shows token counts and tracks session and weekly usage limits with visual load bars on Claude, ChatGPT, and Gemini.

  • Counts tokens locally in the browser with a bundled tokenizer (o200k_base)
  • Reads usage data from each platform's own pages using the user's existing logged-in session
  • Uses an injected bridge script that talks to the content script

Built with AI assistance, and uses the open-source gpt-tokenizer library (MIT).
